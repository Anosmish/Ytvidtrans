## ✨ Highlights

• **Effortless video transcription**: Get accurate, AI-powered transcriptions in seconds.
• **Scalable and maintainable**: Built on Flask and Python for seamless growth and updates.
• **Easy to integrate**: Use our simple APIs to embed transcription capabilities into your apps.

## 🚀 Features

• **Real-time transcription**: Stream media and get instant transcriptions.
• **Multi-language support**: Transcribe content in over 100 languages.
• **Customizable output**: Select transcription format and metadata.

## 🔥 Problem -> Solution

Struggling to keep up with video content demands? Ytvidtrans automates transcription, making it easier to create accessible, engaging, and informative experiences for your audience.

## 🧱 Tech Stack

* **Backend**: Flask (Python Web Framework)
* **Languages**: HTML, Python
* **Databases/Tools**: Python
* **Dependency Signals**: deep-translator, edge-tts, flask, flask-cors, googletrans, requests

## ⚡ Quick Start

### Clone and Install

```bash
git clone https://github.com/Anosmish/Ytvidtrans.git
cd Ytvidtrans
pip install -r requirements.txt
```

### Run the App

```bash
python app.py
```

### Use the API

```bash
curl -X POST \
  http://localhost:5000/transcribe \
  -H 'Content-Type: application/json' \
  -d '{"media_url": "https://example.com/video.mp4"}'
```
